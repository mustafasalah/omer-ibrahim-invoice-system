# متطلبات تصدير PDF

## 1. الهدف

إنشاء ملف PDF مطابق قدر الإمكان لمعاينة وطباعة A4، محليًا ودون اتصال بالإنترنت، مع اسم آمن ومحتوى ثابت.

## 2. النهج المقترح

- مسار HTML مخصص للطباعة يستخدم نفس مكونات وCSS الطباعة.
- محرك Chromium محلي headless يستدعيه الخادم.
- لا يستخدم المتصفح العادي وحده لتوليد الملف لأن تسمية الملف وأرقام الصفحات والثبات أقل قابلية للتحكم.
- لا تُرسل الفاتورة إلى خدمة PDF خارجية.

## 3. عقد التصدير

طلب التصدير:

```json
{
  "invoiceId": "uuid",
  "includeStampAndSignature": true,
  "colorMode": "COLOR",
  "paperFormat": "A4"
}
```

الخيارات المسموحة مقيدة server-side. لا يقبل الطلب HTML أو مسار ملف أو URL.

## 4. خطوات التوليد

1. التحقق من الجلسة وصلاحية قراءة الفاتورة.
2. تحميل الفاتورة والبنود واللقطة والحركات في قراءة متسقة.
3. توليد token داخلي أحادي الاستخدام لمسار الطباعة.
4. فتح المسار في Chromium المحلي.
5. انتظار:
   - DOM ready.
   - الخطوط `document.fonts.ready`.
   - اكتمال كل الصور.
   - إشارة `window.__PRINT_READY__ = true`.
6. توليد PDF بـprint background.
7. التحقق من أن الناتج PDF صالح وغير فارغ وحجم الصفحة A4.
8. بث الملف للمستخدم دون حفظ دائم افتراضيًا.
9. تسجيل حدث `INVOICE_PDF_EXPORTED` دون تخزين محتوى الملف.

## 5. اسم الملف

الصيغة:

```text
Invoice_<invoice-number>_<beneficiary-name>.pdf
```

مثال:

```text
Invoice_OI-2026-00128_مستشفى-الأمل-التخصصي.pdf
```

التنظيف:

- استبدال `/ \ : * ? " < > |` بشرطة.
- ضغط المسافات والشرطات المتكررة.
- إزالة النقاط والمسافات من نهاية الاسم.
- حد أقصى 120 حرفًا قبل `.pdf`.
- إذا كان اسم المستفيد فارغًا: `Unknown-Beneficiary`.
- الحفاظ على Unicode العربي.
- `Content-Disposition` يتضمن `filename` ASCII fallback و`filename*` UTF-8.

## 6. خصائص PDF

- حجم A4 فعلي.
- اتجاه Portrait.
- خلفيات مطبوعة.
- خطوط مضمّنة بالكامل أو subsets.
- صور بدقة مناسبة دون تضخيم.
- رقم الصفحة.
- metadata:
  - Title: رقم الفاتورة واسم المستفيد.
  - Author: OMER IBRAHIM MEDICAL SUPPLIES.
  - Subject: Sales Invoice.
- عدم وضع كلمات مرور أو تشفير في MVP.
- النص يظل قابلًا للتحديد والبحث؛ لا تحول الصفحة إلى صورة.

## 7. التوافق مع الطباعة

- مصدر CSS واحد لمعاينة الطباعة وPDF.
- يسمح بفروقات موثقة فقط في header/footer الخاص بمحرك PDF.
- اختبار visual regression لصفحات مرجعية.
- أي تغيير لقالب الطباعة يختبر PDF في نفس Pull Request.

## 8. الختم والتوقيع

- الخيار يقرأ من لقطة الفاتورة الصادرة.
- عدم التضمين يخفي العنصر في DOM المطبوع، لا يرسل صورة مخفية بحجم كامل دون حاجة.
- لا يحدث أي تغيير في `app_settings` أو `media_assets`.
- إذا كانت الصورة مفقودة فعليًا، يسجل خطأ بيانات ويولد المتاح بعد تحذير المستخدم، أو يرفض إذا كانت سياسة المنشأة تتطلبها.

## 9. الأمان

- مسار الطباعة الداخلي غير متاح دون token قصير العمر.
- يمنع SSRF: لا توجد URLs خارجية.
- يعطل JavaScript غير المطلوب داخل صفحة الطباعة.
- لا يقبل قوالب يكتبها المستخدم.
- يعزل عملية Chromium بحدود زمن وذاكرة.
- ينظف الملفات المؤقتة حتى عند الفشل.
- لا يستخدم اسم المستفيد مباشرة كمسار.

## 10. الأداء والحدود

| الحالة | الهدف |
|---|---:|
| 1–5 صفحات | ≤ 10 ثوانٍ |
| 6–20 صفحة | ≤ 20 ثانية |
| الحد الزمني الصلب | 30 ثانية |
| حجم ملف معتاد | أقل من 5 MB |
| التوليد المتزامن | طابور محلي محدود، افتراضيًا عمليتان |

إذا امتلأ الطابور، تعرض رسالة «جارٍ تجهيز ملف آخر؛ سيبدأ ملفك بعد لحظات» بدل تشغيل عمليات غير محدودة.

## 11. الأخطاء

| الرمز | المعنى | رسالة الواجهة |
|---|---|---|
| `PDF_DATA_INVALID` | فاتورة/لقطة ناقصة | تعذر تجهيز الفاتورة؛ راجع بياناتها |
| `PDF_ASSET_MISSING` | أصل مطلوب مفقود | بعض الصور غير متاحة |
| `PDF_RENDER_TIMEOUT` | تجاوز الوقت | استغرق الملف وقتًا أطول؛ حاول مجددًا |
| `PDF_ENGINE_UNAVAILABLE` | المحرك غير جاهز | خدمة PDF المحلية غير متاحة |
| `PDF_OUTPUT_INVALID` | ناتج تالف | تعذر إنشاء ملف صالح |

لا تعرض stack trace أو مسارًا محليًا.

## 12. معايير القبول

- الملف يبدأ بتوقيع PDF صالح.
- كل الصفحات A4.
- رأس الجدول يتكرر.
- لا ينقسم صف عادي بين الصفحات.
- العلامة المائية صحيحة.
- خيار الختم والتوقيع ظاهر/مخفي حسب الطلب.
- الاسم العربي ينزل بصورة صحيحة على Windows.
- يعمل بعد فصل الإنترنت.
- النص العربي قابل للنسخ بترتيب مقبول.
- لا توجد طلبات شبكة خارجية أثناء التوليد.

## 13. خارج MVP

- توقيع رقمي cryptographic.
- PDF/A.
- حماية بكلمة مرور.
- إرسال بالبريد/واتساب.
- دمج عدة فواتير في ملف واحد.
- تخزين دائم لكل نسخة PDF.
