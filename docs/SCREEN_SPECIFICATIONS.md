# مواصفات الشاشات

## 1. هيكل التطبيق

### التنقل الرئيسي

1. لوحة التحكم.
2. أرشيف الفواتير.
3. فاتورة جديدة.
4. التقارير.
5. الإعدادات.
6. المستخدمون.
7. سجل العمليات.

الشريط الجانبي ثابت على سطح المكتب، ويتحول إلى شريط أفقي/قائمة في العرض الصغير. تعرض كل صفحة عنوانًا، سياق التاريخ، المستخدم، وحالة الاتصال بالخادم المحلي.

## 2. حالات مشتركة

كل شاشة بيانات يجب أن تصمم الحالات التالية:

- Loading skeleton.
- Empty state حقيقية.
- No search results.
- Inline validation.
- Server unavailable.
- Permission denied.
- Stale data conflict.
- Success toast غير معيق.
- Unsaved changes.

## 3. شاشة تسجيل الدخول

**المسار:** `/login`  
**الوصول:** عام.

### التخطيط

- جزء هوية المنشأة: الشعار، الاسمان العربي والإنجليزي، عبارة «نظام إدارة الفواتير».
- بطاقة دخول بعرض 420px تقريبًا.
- مؤشر «يعمل محليًا» وعنوان الجهاز دون كشف معلومات تقنية زائدة.

### الحقول

- اسم المستخدم.
- كلمة المرور مع إظهار/إخفاء.
- زر «تسجيل الدخول».

### السلوك

- Enter يرسل.
- الزر يعطل أثناء الطلب.
- رسالة الخطأ عامة.
- لا يوجد «نسيت كلمة المرور» عبر البريد؛ تظهر عبارة «راجع مدير النظام».
- أول مستخدم يرى تغيير كلمة المرور بعد الدخول.

### إتاحة الوصول

- تركيز تلقائي على اسم المستخدم.
- labels فعلية.
- لا تعتمد رسالة Caps Lock وحدها على اللون.

## 4. لوحة التحكم

**المسار:** `/`  
**الوصول:** مدير وموظف.

### المحتوى

- عنوان وترحيب وزر «إنشاء فاتورة».
- بطاقات:
  - قيمة الفواتير الصادرة للشهر.
  - المدفوع.
  - المتبقي.
  - عدد الفواتير.
  - المسترد اختياريًا كبطاقة خامسة أو في ملخص.
- جدول أحدث 5–10 فواتير.
- قائمة الفواتير المتأخرة/القريبة.
- اختصارات: تسجيل دفعة، البحث، التقارير.

### القواعد

- لا تدخل المسودات والملغاة في قيمة المبيعات.
- المؤرشفة تدخل في الأرقام.
- كل بطاقة توضح الفترة.
- الضغط على بطاقة يفتح الأرشيف بفلتر مناسب.

## 5. إنشاء فاتورة

**المسار:** `/invoices/new`  
**الوصول:** مدير وموظف.

### الرأس

- Breadcrumb: الفواتير ← فاتورة جديدة.
- حالة «لم تحفظ بعد» ثم رقم الفاتورة بعد أول حفظ.
- أزرار ثابتة: حفظ مسودة، إصدار، المزيد.

### أقسام الصفحة

#### 5.1 معلومات الفاتورة

- تاريخ الفاتورة.
- تاريخ الاستحقاق اختياري.
- العملة للقراءة فقط من الإعدادات.
- مؤشر الضريبة المفعلة.

#### 5.2 المستفيد

- حقل اسم autocomplete.
- هاتف، عنوان، رقم ضريبي/تسجيل.
- عند الاقتراح: الاسم والهاتف وزر حذف صغير.
- زر «مسح الاختيار» يعيد الحقول مستقلة.

#### 5.3 البنود

جدول سطح المكتب:

| العمود | العرض التقريبي |
|---|---:|
| ترتيب | 4% |
| المنتج والوصف | 30% |
| الوحدة | 10% |
| الكمية | 10% |
| سعر الوحدة | 14% |
| الخصم | 12% |
| الضريبة | 9% |
| الإجمالي | 11% |

- صف رأس ثابت عند التمرير داخل القائمة الطويلة.
- زر إضافة بند أسفل الجدول.
- قائمة بند تسمح بالتكرار والحذف والتحريك.
- الإجمالي LTR ومحاذى لنهاية العمود.

#### 5.4 الملاحظات والشروط

- ملاحظات داخل الفاتورة.
- شروط دفع تبدأ بالقيمة الافتراضية وقابلة للتعديل.

#### 5.5 ملخص الحساب

بطاقة sticky على جانب الصفحة في العرض الواسع:

- المجموع قبل الخصم.
- خصم البنود.
- خصم الفاتورة مع النوع والقيمة.
- الضريبة.
- الإجمالي النهائي بخط بارز.

### منع الفقد

- حفظ تلقائي ليس مطلوبًا في MVP لتجنب مسودات غير مقصودة.
- تحفظ نسخة مؤقتة في ذاكرة المتصفح أثناء الجلسة فقط.
- تحذير قبل المغادرة.

## 6. تعديل فاتورة

**المسار:** `/invoices/:id/edit`

تعيد استخدام محرر الإنشاء مع اختلافات:

- رقم الفاتورة ظاهر وغير قابل للتعديل.
- شارة الحالة.
- معلومات من أنشأ وآخر تعديل.
- للصادرة: شريط تحذير، حقل سبب تعديل إلزامي للمدير.
- للملغاة: لا يفتح مسار التحرير.
- للمؤرشفة: شاشة منع مع زر إلغاء الأرشفة.
- عند وجود حركات: ملخص صافي المحصل والحد الأدنى المسموح للإجمالي.

## 7. معاينة الفاتورة

**المسار:** `/invoices/:id/preview`

### التخطيط

- خلفية رمادية وأوراق A4 بيضاء.
- شريط أدوات خارج الورقة:
  - رجوع.
  - تكبير/تصغير.
  - ألوان/أبيض وأسود.
  - طباعة.
  - تنزيل PDF.
- لا تدخل أدوات المعاينة في الطباعة.

### المحتوى

- نفس قالب الطباعة الرسمي.
- فاصل واضح بين الصفحات.
- يظهر عدد الصفحات بعد اكتمال التخطيط.
- المسودة والملغاة تحمل علامة مائية.
- خيار الختم والتوقيع لا يتغير مباشرة دون نافذة تأكيد.

## 8. نافذة خيارات الطباعة وPDF

**النوع:** Modal.

### المحتوى

- عنوان يتغير: «خيارات الطباعة» أو «خيارات PDF».
- بطاقتا اختيار:
  - تضمين الختم والتوقيع.
  - بدون الختم والتوقيع.
- تنبيه إن لم تكن الصور مرفوعة.
- اختيار المظهر: ألوان، أبيض وأسود.
- تنسيق الورق: A4 للقراءة فقط في MVP.
- معاينة مصغرة توضيحية.
- زر الإجراء الأساسي وزر إلغاء.

### القواعد

- الاختيار الافتراضي هو آخر اختيار في الجلسة، وليس إعدادًا دائمًا.
- إذا اختار التضمين ولا توجد صورة، يستمر بما هو متوفر بعد توضيح ذلك.
- لا يرفع أو يحذف أصلًا من هذه النافذة.

## 9. أرشيف الفواتير

**المسار:** `/invoices`

### شريط الأدوات

- بحث موحد.
- زر فلاتر متقدمة مع badge بعدد الفلاتر.
- زر إنشاء فاتورة.
- خيار عرض: جدول أو كثافة مريحة/مضغوطة.

### الفلاتر

- حالة الفاتورة متعددة الاختيار.
- حالة الدفع متعددة الاختيار.
- من/إلى تاريخ الفاتورة.
- من/إلى تاريخ الاستحقاق.
- حد أدنى/أقصى للمبلغ.
- المستخدم المنشئ.
- الأرشفة: النشطة، المؤرشفة، الجميع.
- المتأخرة فقط.

### الجدول

- اختيار متعدد.
- رقم الفاتورة.
- المستفيد.
- التاريخ والاستحقاق.
- حالة الفاتورة.
- حالة الدفع.
- الإجمالي والمتبقي.
- المنشئ.
- إجراءات.

### الإجراءات

- فتح التفاصيل.
- تعديل بحسب القواعد.
- نسخ.
- معاينة/طباعة/PDF.
- أرشفة/استعادة.
- إلغاء للمدير.

### الصفحات

- 25 افتراضيًا، 50 أو100 اختياريًا.
- فرز من الخادم.
- تعرض النتيجة «1–25 من 1,240».
- يحفظ query في URL لتسهيل العودة.

## 10. تفاصيل الفاتورة

**المسار:** `/invoices/:id`

### الرأس

- الرقم LTR.
- شارات: الحالة، الدفع، الأرشفة.
- أزرار أساسية حسب الحالة:
  - تسجيل دفعة.
  - استرداد للمدير.
  - معاينة وطباعة.
  - تعديل.
  - المزيد.

### بطاقات مالية

- الإجمالي.
- إجمالي المدفوع.
- إجمالي المسترد.
- صافي المحصل.
- المتبقي.

### التبويبات

#### الفاتورة

- بيانات المستفيد.
- جدول البنود.
- تفاصيل الحساب.
- الملاحظات والشروط.
- بيانات الإنشاء والتعديل.

#### الدفعات والاستردادات

- Timeline أو جدول موحد.
- نوع الحركة، المبلغ، التاريخ، الطريقة، المرجع، المنفذ، الحالة.
- الحركات المبطلة لا تختفي.

#### السجل

- أحداث هذه الفاتورة فقط.
- وصف مختصر وتفاصيل قبل/بعد عند المدير.

### التحذيرات

- تعديل بعد الإصدار.
- إلغاء مع صافي محصل.
- استحقاق متأخر.
- لقطة طباعة ناقصة أصلًا.

## 11. نافذة تسجيل دفعة

**الوصول:** مدير وموظف.

### أعلى النافذة

ملخص: الإجمالي، المدفوع، المتبقي.

### الحقول

- المبلغ؛ افتراضيًا المتبقي.
- تاريخ الدفعة.
- طريقة الدفع.
- تفاصيل «أخرى» عند الحاجة.
- رقم مرجع اختياري.
- ملاحظات.

### السلوك

- عرض «بعد التسجيل: مدفوعة بالكامل/جزئيًا».
- منع قيمة أكبر من المتبقي مع إظهار الحد.
- زر واحد واضح «تسجيل الدفعة».
- لا يغلق بالنقر خارج النافذة بعد بدء الإدخال دون تحذير.

## 12. نافذة تسجيل استرداد

**الوصول:** مدير فقط.

### الملخص

- إجمالي المدفوع.
- المسترد سابقًا.
- القابل للاسترداد.

### الحقول

- المبلغ.
- التاريخ.
- طريقة الرد.
- ربط بدفعة اختياري.
- سبب إلزامي.
- ملاحظة اختيارية.

### السلوك

- معاينة صافي المحصل والمتبقي والحالة الناتجة.
- تحذير: «الاسترداد لا يلغي الفاتورة».
- زر أحمر هادئ «تسجيل الاسترداد».
- تأكيد نهائي يتضمن المبلغ ورقم الفاتورة.

## 13. التقارير

**المسار:** `/reports`

### الشريط العلوي

- فترة مخصصة.
- فترات سريعة: اليوم، هذا الأسبوع، هذا الشهر، هذا العام.
- طباعة، PDF.

### بطاقات

- قيمة الفواتير.
- المدفوع.
- المسترد.
- صافي المحصل.
- المتبقي.
- عدد الفواتير.

### الرسوم والجداول

- اتجاه المبيعات اليومي/الشهري.
- توزيع حالات الدفع.
- أعلى المستفيدين.
- أكثر المنتجات ظهورًا.
- جدول المتأخرات.

### التفاعل

- hover/focus يعرض قيمة دقيقة.
- الضغط ينقل للأرشيف بفلاتر.
- الرسوم لها جدول بديل أو ملخص نصي.
- لا تعرض «الأرباح».

## 14. الإعدادات

**المسار:** `/settings`  
**الوصول:** مدير.

### التبويبات

1. بيانات المنشأة.
2. تصميم الفاتورة.
3. الضرائب والعملة.
4. ترقيم الفواتير.
5. الطباعة والتاريخ.
6. النسخ الاحتياطي.
7. الوصول المحلي/الجلسة.

### بيانات المنشأة

- الأسماء، العنوان، الهواتف، البريد، التسجيل.
- رفع الشعار مع معاينة.

### تصميم الفاتورة

- الختم والتوقيع.
- شعارات الوكلاء حتى خمسة.
- سحب للترتيب.
- نص التذييل.
- شروط الدفع الافتراضية.
- معاينة مصغرة.

### العملة والضريبة

- رمز العملة والكود والمنازل.
- مفتاح تفعيل الضريبة.
- النسبة الافتراضية.
- توضيح أن التغيير للفواتير الجديدة.

### الترقيم

- Pattern builder مقيد.
- بادئة.
- بداية التسلسل.
- سياسة إعادة البدء.
- معاينة الرقم القادم.

### النسخ الاحتياطي

- زر إنشاء وتنزيل.
- آخر نسخة أنشأها النظام.
- منطقة استعادة منفصلة بصريًا وخطرة.
- شرح أن الملف يشمل الصور.

## 15. إدارة المستخدمين

**المسار:** `/users`  
**الوصول:** مدير.

### القائمة

- الاسم، اسم الدخول، الدور، الحالة، آخر دخول، تاريخ الإنشاء.
- بحث وفلتر حالة/دور.
- قائمة إجراءات.

### إنشاء/تعديل

- Drawer أو modal.
- الاسم الظاهر، اسم المستخدم، الدور.
- كلمة مؤقتة عند الإنشاء/إعادة التعيين.
- مفتاح نشط.
- تحذير آخر مدير.

لا يوجد زر حذف.

## 16. سجل العمليات

**المسار:** `/audit-log`  
**الوصول:** مدير.

### الفلاتر

- التاريخ.
- المستخدم.
- نوع العملية.
- رقم الفاتورة.
- بحث في الوصف.

### الجدول

- الوقت.
- المستخدم.
- العملية.
- الفاتورة.
- الوصف.
- زر التفاصيل.

### التفاصيل

- عرض قبل/بعد منظم.
- إخفاء hashes وtokens وكلمات المرور.
- JSON الخام غير معروض افتراضيًا.
- للقراءة فقط.

## 17. الاستجابة للأحجام

| العرض | السلوك |
|---|---|
| ≥ 1280px | شريط جانبي كامل، محرر بعمودين، جداول كاملة |
| 960–1279px | شريط أضيق، ملخص الحساب أسفل/جانب |
| 768–959px | تنقل قابل للطي، جداول بتمرير أفقي مضبوط |
| < 768px | دعم عرض ومراجعة أساسي؛ البنود كبطاقات |

النظام موجّه أساسًا لسطح المكتب. لا تُخفى وظائف مهمة على الجهاز اللوحي، لكن الهاتف ليس هدف العمل المكثف في MVP.

## 18. اختصارات لوحة المفاتيح

- `Alt + N`: فاتورة جديدة.
- `Ctrl/Cmd + S`: حفظ مسودة.
- `Ctrl/Cmd + K`: تركيز البحث.
- `Ctrl/Cmd + P`: فتح خيارات الطباعة داخل النظام، لا الطباعة مباشرة.
- `Esc`: إغلاق نافذة إن لم توجد بيانات غير محفوظة.

تعرض الاختصارات في tooltips ولا تستبدل الأزرار.
